## Portability boundary

This file is an audit ledger, not portable runtime guidance. Some historical
provenance rows intentionally preserve maintainer-specific archived evidence paths
from the workspace where the manifest was generated. Colleagues should use the
routed handbooks, source map, current official docs, and available retrieval
tools for runtime grounding instead of treating those archived local paths as
portable inputs.

## Evidence And Inclusion Legend

- `current official`: current ODC docs represented by the official `docs-odc` repository.
- `official archived`: local official archived PDF or text material.
- `official course/example`: official course, workshop, markdown, or `.oml` asset.
- `direct`: materially changes syntax, placement, logic design, or runtime behavior.
- `supporting`: materially improves architecture, testing, security, deployment, troubleshooting, or enterprise guidance.
- `context-only`: retained for audit completeness or low-signal background context.
- `full`: distilled into a main reference section.
- `summary`: distilled into concise guidance or used as secondary context.
- `catalog-only`: retained only in the manifest so it is not silently omitted.
